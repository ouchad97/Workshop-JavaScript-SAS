Introduction

Pourquoi apprendre JavaScript ?

JavaScript est un langage polyvalent utilisé dans les navigateurs, les serveurs et de nombreux environnements de développement. Vous apprendrez sa syntaxe et ses outils fondamentaux en pratiquant.

Mise en place

Prérequis et premier test

Installez Node.js avant de commencer. Vérifiez ensuite l'installation dans le terminal :

node --version

Pour tester un fichier JavaScript, créez un fichier test.js contenant :

console.log("Bonjour JavaScript !");

Exécutez-le depuis le dossier du fichier :

node test.js
